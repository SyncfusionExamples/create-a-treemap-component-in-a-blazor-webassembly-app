# Create a TreeMap Component in a Blazor WebAssembly App

A quick-start project that helps you create a Blazor TreeMap of Syncfusion in a Blazor WebAssembly application. This sample highlights prominent features such as enabling leaf labels, applying color mapping to ranges, showing legends, and adding titles for clarity.

**Documentation**: https://blazor.syncfusion.com/documentation/treemap/getting-started

**Online example**: https://blazor.syncfusion.com/demos/treemap/default-functionalities

## Project overview

This sample demonstrates how to integrate the Syncfusion TreeMap control into a Blazor WebAssembly app and enable common visual features and settings. It is intended as a quick reference for developers learning to configure visual mappings and labels.

## Features

- Leaf labels: show labels for leaf nodes to surface values and names.
- Color mapping: apply color ranges to values for visual grouping.
- Legends: display legends explaining color ranges.
- Titles: add descriptive titles to the visualization.

## Prerequisites

- Visual Studio 2022 with Blazor development workload (or equivalent .NET SDK installed).

## How to run the project

- Checkout this project to a location on your disk.
- Open the solution file using Visual Studio 2022.
- Restore NuGet packages by rebuilding the solution, or use `dotnet restore` and `dotnet build`.
- Run the project from Visual Studio or with `dotnet run` for the Server/host project.
